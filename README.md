## Sobre mí

Desarrolladora Full Stack en formación con enfoque en la construcción de aplicaciones web completas, desde el diseño de APIs REST con Java y Spring Boot hasta la creación de interfaces modernas con React. Me interesa especialmente escribir código limpio, mantenible y bien estructurado.

Actualmente trabajando en proyectos reales que combinan backend robusto con frontend funcional, aplicando buenas prácticas de arquitectura en capas, validaciones, manejo de excepciones y control de versiones con Git.

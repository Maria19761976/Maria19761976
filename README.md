### Backend — Agencia de Viajes
API REST completa desarrollada con Spring Boot para la gestión de una agencia de viajes. Incluye gestión de usuarios, hoteles, viajes, reservas, conductores y autobuses con lógica de negocio avanzada.

**Tecnologías:** `Java 17` `Spring Boot` `MySQL` `JPA` `Lombok` `Cloudinary` `JavaMail`

**Lo que aporté:**
- Arquitectura en capas: Controller / Service / Repository / DTO / Mapper
- Validaciones con `@Valid`, `@NotBlank`, `@Pattern`, `@Size` en los DTOs
- `GlobalExceptionHandler` para manejo centralizado de errores
- Módulo completo de viajes con validación de fechas y disponibilidad
- Integración con la rama de desarrollo mediante Pull Requests
